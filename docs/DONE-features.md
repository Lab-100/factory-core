# Внесённые доработки ядра (рейтинг, синтез, рассуждения, туду-лист)

Дата: 22.10.2026. Все изменения собраны в `factory.exe` и развёрнуты
(рабочая копия Lab-100, веб-чат на 127.0.0.1:8787).

## 1. Рейтинговый движок выбора провайдера (`factory/ratings.py` — новый модуль)

- Ведёт статистику по каждому провайдеру в `state/ratings.jsonl`:
  число запросов, успехов/отказов, совокупное и среднее время ответа,
  специализация по компетенциям.
- Выбор провайдера (`ExternalAgentAdapter._pick`) учитывает:
  надёжность (доля успехов, с прижатием к нейтрали при малой выборке),
  скорость, специализацию, квоты (исчерпавшие не берём).
- Интеграция: `external_agent.py` — `_pick` выбирает по рейтингу,
  `_run_single` фиксирует метрики (успех/отказ + время).
- Веса настраиваются в `config/settings.toml -> [ratings]`
  (`rate`, `speed`, `spec`, `min_samples`, `neutral`).

## 2. Синтез ответов с кругом доводки (`factory/adapters/external_agent.py`)

- Синтез: опрос нескольких исполнителей параллельно, сведение ответов
  оркестратором (уже был). Доработан «круговой доводкой»:
  - оркестратор оценивает ответ (`_assess`: ok / weak / bad);
  - при слабом, пустом или сбойном результате — повторяет с уточнением
    (по умолчанию до `synth_rounds = 3`, настраивается в `[synth]`);
  - после всех раундов отдаёт лучший полученный ответ или явную ошибку.
- Параметры синтеза — из `config/settings.toml -> [synth]`
  (`count`, `rounds`, `timeout_s`).

## 3. Показ рассуждений моделей пользователю

- В синтезе каждый опрошенный провайдер пишет свои рассуждения (или сбой)
  в поток размышлений (`stream_file`); веб-чат показывает их в блоке
  «Поток» без ожидания конца обработки.

## 4. Туду-лист запроса в веб-чате фабрики (`factory/jobs.py`, `factory/ui/web.py`)

- При старте задачи план превращается в пункты туду-листа (`job.todo`).
- Пункты зачёркиваются по мере выполнения шагов (обновляется в реальном
  времени через `/api/jobs/get`).
- В веб-чате над полем ввода появился блок туду-листа (`#todoBox`):
  список пунктов, сворачивается в мини-овал со счётчиком «сделано/всего»,
  раскрывается кликом.

## Сборка

```
cd factory-core
python -m PyInstaller --noconfirm factory.spec --distpath dist --workpath build
```

Готовый `dist/factory.exe` копируется поверх рабочего
`%LOCALAPPDATA%\Programs\FactoryLab100\factory.exe`
(старые версии сохраняются бэкапами `factory.exe.bak-*`).

## Примечание о самопочинке

Фабрика включает self-heal (задача планировщика `FactoryLab100-SelfHeal`,
аргументы `-Fix -Publish -Wait 600`): завершённую работу коммитит и публикует
(`-Publish`), а в `git stash` убирает только битое (`-Fix`). Правки, уже
попавшие в git-историю, не теряются.
